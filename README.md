# SLH Lab – Ecosystem Control Center

## תיאור
מערכת שליטה ובקרה ל-Ecosystem של SLH. כולל Dashboard עם 23 Nodes, לוגים בזמן אמת, גרף עומס, דף סוכנים ודף פרומפטים.

## טכנולוגיות
- HTML5/CSS3/JavaScript
- Chart.js
- GitHub Pages

## מבנה
- index.html – לוח בקרה ראשי
- gents.html – רשימת סוכני המערכת
- prompts.html – הוראות עבודה קבועות
- deploy.ps1 – סקריפט פריסה אוטומטי
